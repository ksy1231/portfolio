The Global Challenge

  • Urban Congestion Drivers in major cities spend 15+ minutes circling for parking, increasing emissions.
  • Hidden Free Options Mainstream navigation tools prioritize paid lots, burying cost-free alternatives.
  • Complex Local Bylaws Municipal parking rules are often cryptic and hard for drivers to interpret instantly.

The Smart Solution

  • Places API v1 Intelligence Advanced metadata filtering to isolate free zones and mixed-use retail lots.
  • AI Bylaw Interpreter Gemini AI simplifies complex regional laws into "Parkable" or "Not Parkable" status.
  • Walking Route Engine Real-time pathfinding ensuring spots are within a practical, reachable distance.

Experience-Driven Features

Blending Artificial Intelligence with intuitive UI.

AI Parking Law Interpreter

Powered by Google Gemini AI. It translates complex municipal bylaws into simple terms: "You can park here for max 2 hours until 9 PM." Results are cached locally to save API costs.

Parked Here Persistence

Mark your car's location with a single tap. The spot turns Violet and persists across app sessions using AsyncStorage, ensuring you never lose your car.

Engineering Excellence

Focusing on performance, cost-efficiency, and a DRY (Don't Repeat Yourself) architecture.

40% API Billing Reduction Through Field Masking & Debounce Logic
100% Code Reuse Shared business logic across Web & Mobile

Platform Resolver

Implemented environment-specific map rendering using .native.tsx and .web.tsx extensions, allowing React Native Maps and Google Maps JS API to coexist seamlessly.

Field Masking

Optimized Places API v1 calls by requesting only essential fields (name, type, status). This minimizes the payload and significantly lowers the cost per request.

Response Caching

AI-generated parking rules are stored in AsyncStorage indexed by city name. This ensures that users visiting the same city never trigger a redundant AI query.

Route Intelligence

Integrated Google Routes API to replace straight-line distance with real walking time, accounting for physical barriers like highways.
